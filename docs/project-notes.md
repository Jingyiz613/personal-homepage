# 项目笔记与决策记录（Project Notes）

## 一、项目定义

- **项目名称**：个人主页（Personal Homepage）
- **目标用户**：自己，以及想了解我的同学、老师、潜在合作者
- **要解决的问题**：需要一个集中展示「我是谁、我在学什么、我做过什么」的入口
- **解决方案**：一个发布于 GitHub Pages 的单页网站，包含个人信息、音乐互动、专辑收藏、数字分身、学习课程、成长时间线、访客反馈与联系方式；反馈由 Supabase 持久化保存
- **核心功能（当前版本）**：
  1. 首页 Hero 区（头像、姓名、一句话介绍）
  2. 个人信息展示区（姓名、介绍、身份、兴趣、特点）
  3. 数字分身聊天区（关键词匹配问答）
  4. 学习与课程
  5. 成长时间线
  6. 访客反馈（Supabase 后端存储，仅站长在后台查看）
  7. 联系方式
- **明确不做什么**：
  - 不做访客登录，不公开读取、修改或删除反馈
  - 不开发独立后台管理网页，由站长在 Supabase Table Editor 查看反馈
  - 数字分身暂用「关键词匹配」，不接入真实大模型 API（后续可作为扩展）

## 二、技术决策

| 决策点 | 选择 | 理由 |
| --- | --- | --- |
| 实现方式 | 纯静态 HTML/CSS/JS | 易上手、易部署、易留 Git 记录 |
| 配色 | 少女风（奶油粉 + 薰衣草紫） | 符合个人审美定位 |
| 布局 | 单页滚动 + 锚点导航 | 信息集中、移动端友好 |
| 动画 | 原生 CSS + IntersectionObserver | 轻量、无需引入第三方库 |
| 数字分身 | 关键词匹配问答（纯前端） | 无需后端/API，演示稳定；后续可升级接入大模型 |
| 反馈后端 | Supabase PostgreSQL + RLS | 静态网站可以安全提交真实反馈，匿名访客仅有 INSERT 权限 |
| 发布 | GitHub Pages | 与现有静态结构匹配，更新和版本回退简单 |
