# 个人主页（Personal Homepage）

这是我的 Vibe Coding 第一个项目。V2 第一阶段把页面改造成「夜晚轻像素创意工作室」，保留原有个人信息与内容。V2.5 统一了内容板块之间的过渡、卡片层次和聊天区细节。V2.6 将个人信息区改成工作室留言板式卡片。

## V3 访客反馈（开发中）

- 在联系方式前新增「给我一点反馈」入口，通过无跳转弹窗收集昵称、关系、设备和反馈内容。
- 反馈写入 Supabase `feedback` 表；匿名访客只有新增权限，不能公开读取、修改或删除记录。
- 表单包含必填校验、字数提示、设备识别、防重复点击、隐藏诱捕字段，以及明确的成功和失败状态。
- 数据库表与 RLS 策略位于 `supabase/feedback.sql`。前端只允许配置 Project URL 和 publishable key，禁止使用 secret/service_role key。
- 完成数据库联调后，将通过 GitHub Pages 发布并分别进行电脑端与手机端线上测试。

## V2.96 窄屏台灯修正

- 窄屏台灯改为图片坐标锚定：根据背景原始尺寸、Hero 高度、86% 缩放和 94% 横向裁切实时计算桌面位置，再将 SVG 底座接触点绑定到原图书桌坐标。屏幕持续变窄时，台灯、桌面、反馈和星星会使用同一套缩放偏移。

## V2.96 流动光标

- 全页加入与夜空配色一致的流动光标：暖金、雾粉、鼠尾草绿与淡紫色尾迹会随移动速度产生惯性、卷曲和自然消散。
- 保留系统原生鼠标，并增加一个柔和发光核心；点击时核心短暂放大变色。
- 效果使用透明 Canvas，完全不拦截页面点击，发光核心实时贴合指针；拖尾采用一条双层渐变丝带与最多 96 个轻量粒子组合，在不恢复高成本模糊的情况下提高可见度，并通过短存活时间与较低 Canvas 像素比保持流畅。
- 桌面端使用完整流动光标；手机端在手指滑动时显示更短、更轻的触摸流光，轻点时显示星光涟漪。减少动态效果模式会关闭两端效果。
## V2.95 成长时间线

- 桌面端使用星轨式双列交错布局，移动端自动切换为单列时间线。
- 卡片加入 Floating Card 效果：鼠标移入时明显上浮、轻微放大并随指针产生 3D 透视倾斜，暖色光晕跟随移动；触屏设备改用按住卡片时上浮并产生较轻的 3D 倾斜，松开或滚动时回正；减少动态效果模式自动关闭倾斜。

## 如何本地预览

直接双击 `index.html`，或用任意静态服务器打开。也可以用浏览器打开文件路径。

反馈数据库接入步骤：

1. 在 Supabase SQL Editor 中完整运行 `supabase/feedback.sql`。
2. 从 Supabase 项目的 Connect 或 API Keys 页面复制 Project URL 和 publishable key。
3. 将两项填入 `js/supabase-config.js`；不要在项目中写入数据库密码、secret key 或 service_role key。
4. 本地提交测试反馈，并在 Supabase Table Editor 中确认记录真实存在。

台灯仅改变插画中的暖光，不影响页面正文亮度，也不会播放声音。欢迎语依据访客浏览器本地时间显示，并不表示站长当前的实时活动。页面支持 `prefers-reduced-motion`。

Hero 使用为台灯互动重新排布桌椅的夜间工作室插画 `images/cozy-studio-lamp-layout.png`。画面保留月亮、云、书架与植物；窄屏时插画从 Hero 顶部铺满背景，文字通过深色渐变保持可读，画面随视口裁切，不再单独排成图片卡片。星星画布与背景使用同一缩放比例，可交互台灯覆盖在书桌左侧前景。

窗外星点由 `js/stars.js` 绘制在与插画窗格对齐的画布上，每颗星星约 3–4 秒完成一次明暗变化，保留间歇出现的两道 CSS 流星。开启系统“减少动态效果”时星星仍会以更柔和的亮度变化闪烁，流星隐藏。

音乐卡片可切换《Hit the Rhyme》和《爱不来》。两首由站长提供的 MP3 已分别存入 `audio/hit-the-rhyme.mp3` 和 `audio/ai-bu-lai.mp3`，打开页面点击播放即可在本页收听，不依赖外部嵌入播放器，也不会自动播放。卡带和波形根据实际播放状态动起来。访客也可以临时为当前曲目更换本地音频文件；此替换只在当前浏览器会话中使用。卡片保留两首歌的官方页面链接。
