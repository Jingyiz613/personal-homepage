# 个人主页（Personal Homepage）

这是我的 Vibe Coding 第一个项目。V2 第一阶段把页面改造成「夜晚轻像素创意工作室」，保留原有个人信息与内容。V2.5 统一了内容板块之间的过渡、卡片层次和聊天区细节。V2.6 将个人信息区改成工作室留言板式卡片。

## V2.8 标题与数字分身

- 方大同专辑板块标题改为「我最爱的歌手——方大同」。
- 数字分身加入站长确认的音乐故事：朋友带着她听方大同、最爱《未来》专辑、最喜欢其中的《公园》。新增音乐快捷问题和随机问题，可接住「为什么喜欢？」「哪张专辑？」等简短追问。
- 学习与课程改为三张柔和纸色的翻转笔记卡片。鼠标移入自动翻开、移开合上；触屏轻点或键盘按 Enter/空格也可翻面查看原有课程说明。减少动态效果时翻面不播放过渡动画。

## V2.7 音乐短句与专辑书架

- 「正在听」与「最近喜欢」分别展示站长指定的歌曲短句。
- 音乐卡片与数字分身之间加入方大同专辑书架：十张正式专辑封面按发行年份堆叠展示。将鼠标移到卡片区滚动滚轮即可逐张翻页，手机上可在卡片区上下滑动；封面、前后按钮、专辑索引和方向键也可切换。
- 专辑封面和年份来自 [Apple Music 方大同艺人页](https://music.apple.com/us/artist/khalil-fong/201549024)及对应专辑页面；封面保存在 `images/albums/`，每张卡片都可打开官方专辑页面。范围包含翻唱专辑《可啦思刻》，不含现场专辑、精选集与 EP。

## V2.6 个人卡片

- 左侧保留姓名和一句话介绍，加入一盆叶片、枝干与花盆连在一起的 SVG 小植物；整株枝叶轻微摇摆。
- 右侧用三张小纸条展示学习、兴趣和个人特点；鼠标悬停时纸条轻微抬起。
- 点击「关于我的小细节」可展开或收起虎牙介绍，支持键盘操作。
- 小屏幕改为单列布局；系统开启减少动态效果时停止纸条与植物的动画。
- 音乐卡片增加浅色慢速飘雪背景；雪花只在卡片可见且页面活跃时更新，系统开启减少动态效果时显示静态雪点。

## V2.5 视觉打磨

- 板块之间改用柔和渐变衔接，减少明显的横向分界线。
- 个人信息、课程、项目和时间线卡片各有轻微的色彩层次；普通内容卡片不再在鼠标经过时突然上浮。
- 聊天区增加温暖的顶部光线、柔和气泡与输入反馈，打字提示改为轻缓呼吸的点点。
- 导航会标出当前浏览的板块，滚动显现距离缩短，并保留减少动态效果设置。
- 首页小房间以外改为连续的深蓝夜空与低对比云雾背景 `images/healing-night-sky.png`，内容区之间用淡雾光衔接；星点只出现在天空上部并缓慢闪烁，卡片保持清晰可读。

## 如何本地预览

直接双击 `index.html`，或用任意静态服务器打开。也可以用浏览器打开文件路径。

台灯仅改变插画中的暖光，不影响页面正文亮度，也不会播放声音。欢迎语依据访客浏览器本地时间显示，并不表示站长当前的实时活动。页面支持 `prefers-reduced-motion`。

Hero 使用去除静态星点的夜间工作室插画 `images/cozy-studio-starless.png`。画面保留温暖台灯、月亮、云、书架与植物；窄屏时插画从 Hero 顶部铺满背景，文字通过深色渐变保持可读，画面随视口裁切，不再单独排成图片卡片。星星画布与背景使用同一缩放比例，台灯按钮覆盖在画面下方。

窗外星点由 `js/stars.js` 绘制在与插画窗格对齐的画布上，每颗星星约 3–4 秒完成一次明暗变化，保留间歇出现的两道 CSS 流星。开启系统“减少动态效果”时星星仍会以更柔和的亮度变化闪烁，流星隐藏。

音乐卡片可切换《Hit the Rhyme》和《爱不来》。两首由站长提供的 MP3 已分别存入 `audio/hit-the-rhyme.mp3` 和 `audio/ai-bu-lai.mp3`，打开页面点击播放即可在本页收听，不依赖外部嵌入播放器，也不会自动播放。卡带和波形根据实际播放状态动起来。访客也可以临时为当前曲目更换本地音频文件；此替换只在当前浏览器会话中使用。卡片保留两首歌的官方页面链接。
