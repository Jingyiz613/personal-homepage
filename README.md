# 个人主页（Personal Homepage）

这是我的 Vibe Coding 第一个项目。V2 第一阶段把页面改造成「夜晚轻像素创意工作室」，保留原有个人信息与内容。

## 项目信息

- 作者：张景怡
- 学校：天津大学香港理工大学深圳未来技术学院
- 专业：计算机科学与技术，2026 级大一
- 课程：Project-Based CST & AI Foundations（44511105）
- 技术栈：HTML + CSS + JavaScript（纯静态，无需构建工具）

## 主要板块

- 首页 Hero：个人介绍、根据访客本地时间变化的欢迎语、可开关台灯
- 个人信息展示区：姓名、介绍、身份、兴趣、特点
- 数字分身聊天区：关键词问答、快捷问题、随机问我、typing 提示与自动滚动
- 学习与课程、项目作品、成长时间线、联系方式

## 如何本地预览

直接双击 `index.html`，或用任意静态服务器打开。也可以用浏览器打开文件路径。

台灯仅改变插画中的暖光，不影响页面正文亮度，也不会播放声音。欢迎语依据访客浏览器本地时间显示，并不表示站长当前的实时活动。页面支持 `prefers-reduced-motion`。

Hero 使用原创夜间工作室插画 `images/cozy-studio.png`。画面以温暖台灯、星空窗景、书架与植物呈现轻像素氛围；移动端会把插画放在个人介绍下方，避免文字压在细节上。

窗外叠加了缓慢闪烁的星点和间歇出现的两道流星，均由 CSS 实现；开启系统“减少动态效果”时会隐藏这些动效。
