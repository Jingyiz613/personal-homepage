# 个人主页（Personal Homepage）

这是我的 Vibe Coding 第一个项目：一个「精美少女风」的个人主页。

## 项目信息

- 作者：张景怡
- 学校：天津大学香港理工大学深圳未来技术学院
- 专业：计算机科学与技术，2026 级大一
- 课程：Project-Based CST & AI Foundations（44511105）
- 技术栈：HTML + CSS + JavaScript（纯静态，无需构建工具）

## 主要板块

- 首页 Hero：头像 + 名字 + 一句话介绍
- 个人信息展示区：姓名、介绍、身份、兴趣、特点
- 数字分身聊天区：关键词匹配的简单问答（可回答名字/专业/兴趣/擅长等）
- 学习与课程、项目作品、成长时间线、联系方式

## 目录结构

```
personal-homepage/
├── index.html          # 页面结构
├── css/
│   └── style.css       # 样式（配色、布局、动画）
├── js/
│   └── main.js         # 交互脚本
├── docs/
│   ├── ai-log.md       # AI 使用日志（课程要求）
│   └── project-notes.md# 项目笔记与决策记录
└── README.md           # 本文件
```

## 如何本地预览

直接双击 `index.html`，或用任意静态服务器打开。也可以用浏览器打开文件路径。
